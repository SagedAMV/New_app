# 📡 تطبيق سجل الميدان – مواقعي (Field Log - Telecom Officer Pro)

تطبيق متكامل لضابط الاتصالات اللاسلكية في المجال العسكري، لإدارة مواقع الاتصالات والمواد والاحتياجات المرتبطة بها، مع تتبع حركات الصيانة الميدانية واستكشاف الأعطال.

---

## 🚀 كيفية تشغيل التطبيق على هاتفك المحمول (Expo Go / Snack):

### 🌟 الطريقة الأولى: التشغيل الفوري عبر المتصفح وسحابة (Expo Snack)
1. افتح رابط بيئة تطوير Expo السحابية: [https://snack.expo.dev](https://snack.expo.dev)
2. قم بإنشاء مشروع جديد، وانسخ الأكواد الموجودة في هذا المجلد (`App.js` ومجلد `src/`).
3. اضغط على التبويب **"My Device / QR Code"** في أعلى يمين الشاشة.
4. افتح تطبيق **Expo Go** على هاتفك المحمول وقم بمسح الباركود، وسيعمل التطبيق بكامل طاقته ومميزاته فوراً!

### 🌟 الطريقة الثانية: التشغيل المحلي عبر جهاز الكمبيوتر (Local Development)
1. افتح موجه الأوامر (Terminal) في مجلد المشروع `field-log-expo`.
2. قم بتثبيت الحزم:
   ```bash
   npm install
   ```
3. قم بتشغيل الخادم:
   ```bash
   npx expo start
   ```
4. امسح رمز الـ QR الظاهر على الكمبيوتر بكاميرا تطبيق **Expo Go** على هاتفك.

## 🛠️ المميزات المدمجة والتكامل الكامل:
1. ✔️ **مكتبة المواد (قاعدة بيانات مستقلة):** تخزين وإدارة مواد وأجهزة الاتصالات (VHF, بطاريات شمسية، هوائيات Yagi، كوابل RG-213...) بمعرفات مستقلة.
2. ✔️ **واجهة إضافة موقع جديد:** إضافة مواقع وربط مواد من المكتبة فوراً مع إمكانية إدراج مادة جديدة لم تكن مسجلة مسبقاً.
3. ✔️ **لوحة المواقع التكتيكية:** عرض جميع المواقع بشكل بطاقات مع تمييز المواقع التي تكون (قيد الاستكشاف) أو (بها أعطال).
4. ✔️ **شاشة تفاصيل الموقع التفاعلية:** خانة مواد تحتاج صيانة وخانة مواد مطلوبة، مع أزرار (سحب للصيانة) و(نزول لاستكشاف عطل).
5. ✔️ **قائمة المهام التلقائية:** تتجمع فيها كل طلبات الصيانة والنواقص من جميع المواقع، وعند إنجاز المهمة تُحذف تلقائياً من الخانة الأصلية للموقع.
6. ✔️ **حركات المواد (سحب وإرجاع):** توثيق سحب الأجهزة للورشة مع التواريخ والملاحظات وإمكانية إرجاعها للموقع للخدمة.
7. ✔️ **استكشاف الأعطال الميداني:** توثيق تقارير النزول، وتوليد مهام صيانة ميدانية تلقائياً عند اختيار (يحتاج صيانة) مع ربط المواد المتضررة.
